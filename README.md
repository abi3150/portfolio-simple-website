# 🌐 Portfolio Website (Home & Contact)

This is a simple portfolio website built using **HTML and CSS**.
It includes a **Home page** and a **Contact page** to showcase basic personal information.

---

## 🚀 Pages Included

### 🏠 Home Page

* Introduction / Welcome message
* Short bio
* Navigation to other pages

### 📞 Contact Page

* Contact form (Name, Email, Message)
* Basic contact details (email, phone)

---

## 🛠️ Technologies Used

* HTML5
* CSS3

---
